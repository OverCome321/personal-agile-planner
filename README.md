# Неделя — личный Agile-планировщик

Учебный проект по дисциплине «Проектная деятельность в ИТ». Вариант: разработка программы планировщика Agile для личного пользования (первая буква фамилии Г).

## Возможности

- Канбан-доска: бэклог, к выполнению, в работе, готово.
- Создание и изменение задач: приоритет, срок, оценка в баллах, заметка.
- Перемещение мышью или выбор состояния с клавиатуры в редакторе.
- Состав текущего спринта, прогресс по баллам и предупреждение о превышении WIP.
- Поиск, фильтр по приоритету, выделение просроченных задач.
- Сохранение в localStorage, проверяемый импорт и экспорт резервной копии JSON.

## Запуск

Нужен Node.js 20 или новее. Внешние библиотеки не требуются.

```sh
npm start
```

Открыть http://127.0.0.1:8741. Для проверки логики: `npm test`.

Данные принадлежат одному пользователю и сохраняются только в браузере на конкретном адресе. Очистка данных браузера удалит задачи; сначала скачайте резервную копию. Сервер слушает только локальный адрес. Авторизация и синхронизация между устройствами в учебном прототипе не реализованы.

Первое открытие показывает шесть учебных задач. Это примеры для демонстрации, а не сведения о фактически выполненной учебной работе.

## Структура

`public/` — интерфейс, `src/domain.js` — проверка данных и расчёт показателей, `server.mjs` — локальная выдача файлов, `tests/` — проверки правил, `docs/` — требования, ИСР и порядок работы с версиями.
