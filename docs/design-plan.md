# Интерфейс личного планировщика

Цель — видеть личный спринт целиком и завершать задачи, не перегружая план.

Палитра: текст #243343, фон #F5F7FA, рабочие области #EAF0F6, действие #2A5E99, готовность #32826A, предупреждение #B3812D. Calibri/Segoe UI: удобный русский текст, заголовки 36/25, карточки 16, подписи 13. Канбан-доска занимает основное место, четыре колонки отражают реальные состояния. Слева — два режима и резервная копия; сверху — одна полоса прогресса. Карточки компактные, с ровным левым краем, без декоративных изображений и анимации. На узком экране колонки выстраиваются вертикально.

В проверке плана исключены лишние показатели и рекламный первый экран: открывается сразу рабочая доска. Содержательная особенность — предупреждение о более чем двух одновременно выполняемых задачах и подсчёт прогресса по оценкам, а не по числу карточек.

Проверка интерфейса: карточка создана, переведена в состояние «Готово» и сохранена после перезагрузки; поиск показал одну подходящую задачу. Экспорт резервной копии выполнен.
