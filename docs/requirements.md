# Требования и критерии готовности

Назначение: один человек ведёт свои задачи и недельные спринты. Основание: учебное задание по варианту В–Д.

F1. Создание и редактирование карточки с названием до 120 символов, заметкой, приоритетом, сроком и целой оценкой 1–21.
F2. Четыре состояния задачи и независимый признак включения в спринт.
F3. Прогресс спринта = сумма баллов готовых задач / сумма баллов всех задач спринта. Пустой спринт: 0%.
F4. Поиск и фильтр не меняют задачи; приоритет определяет порядок.
F5. Данные сохраняются при перезагрузке, экспортируются и восстанавливаются после проверки формата. Повторные идентификаторы и невозможные даты отклоняются.
F6. Весь интерфейс доступен с клавиатуры; перетаскивание имеет альтернативу в форме редактирования.

Ограничения: локальный прототип, без аккаунтов и серверного хранения. В проект не включаются реальные персональные задачи и резервные копии пользователя.

Критерии приемки: проходят тесты логики; в браузере подтверждены создание и редактирование, перемещение, сохранение после обновления, фильтр и экспорт; нет необработанных ошибок; документированы запуск и ограничения.
